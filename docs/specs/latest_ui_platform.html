PTW Design System
Permit to Work · Platform & Business Flows

Four themes, one permit lifecycle

The same draft → approval → execution → closure flow gets used by a welder on a rooftop, an HOD watching a risk dashboard, a first-time worker verifying an OTP, and an Org Owner reconciling an invoice. One visual language can't serve all four honestly — so this system ships four, unified by shared spacing/type/motion scales but deliberately different in colour, shape and voice per audience. Switch themes, density modes, and visual styles above; every component below re-skins live.

Dynamic

Hazard

Rebuilt as a glanceable, wearable-style companion — true-black canvas, heavily rounded tiles, and a different saturated hue per metric, the same grammar as a watch face or iOS widget so a status reads in under a second at arm's length. Concentric rings track compliance the way Activity rings track a workout; colour-coded quick-action tiles replace buried menus for a worker mid-shift.

Corporate

Control Room

A NOC screen, not a brochure. Deep graphite-navy canvas, signal-blue accent, amber/green/red status exactly like a SCADA panel. Mono numerics, hairline grids, glowing focus states, and a live-pulse dot on anything real-time. Desktop-first, dense, built to be stared at for a full shift.

Bridge

Setu

Named for the one bridge every worker crosses once: OTP → PIN → active. Led by a deep trust-green on warm paper — the same "verified / safe-to-work" green as an approved permit — with marigold kept as a small warm accent rather than the lead colour. Baloo 2's rounded warmth, 18–28px radii, springy easing. The signature arch-shaped stepper shapes the onboarding journey as a bridge being crossed.

Thoughtful

Ledger Slate

Where money and audits live, so it reads like a statement, not a dashboard toy. Serif headers (Source Serif 4) over quiet Inter body copy, teal accent, gold reserved for GST/invoice cues, hairline dividers instead of shadows, tabular figures that count up rather than jump.
